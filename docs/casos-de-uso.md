# Casos de Uso - Sistema Guardian

## Caso de Uso 1: Reportar Problema Técnico

**Actor**: Usuario Final  
**Objetivo**: Reportar un problema técnico para recibir soporte

**Flujo Principal**:
1. Usuario accede al sistema
2. Hace clic en "Crear Ticket"
3. Selecciona categoría del problema
4. Describe el problema
5. Adjunta capturas de pantalla (opcional)
6. Envía el ticket
7. Sistema asigna automáticamente un técnico
8. Usuario recibe confirmación por email

**Problema que resuelve**: Usuarios necesitan una forma clara y organizada de reportar problemas sin usar emails dispersos o llamadas telefónicas.

## Caso de Uso 2: Gestionar Tickets Asignados

**Actor**: Técnico de Soporte  
**Objetivo**: Resolver tickets asignados eficientemente

**Flujo Principal**:
1. Técnico inicia sesión
2. Ve lista de tickets asignados
3. Selecciona ticket prioritario
4. Revisa historial y detalles
5. Comunica con usuario
6. Implementa solución
7. Marca ticket como resuelto
8. Usuario recibe notificación

**Problema que resuelve**: Técnicos necesitan priorizar y dar seguimiento a múltiples solicitudes sin perder información.
