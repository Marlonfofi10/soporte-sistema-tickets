# Sistema de Soporte Técnico - Guardian

## 📋 Descripción
Sistema de gestión de tickets de soporte técnico diseñado para facilitar la comunicación entre usuarios y el equipo de soporte, permitiendo un seguimiento eficiente de problemas y solicitudes.

## 🎯 Problema que Resuelve
Muchas organizaciones enfrentan dificultades para gestionar eficientemente las solicitudes de soporte técnico de sus usuarios. Este sistema centraliza y organiza todos los tickets, permitiendo:
- Priorización de casos críticos
- Asignación automática según disponibilidad
- Historial completo de cada caso
- Métricas de tiempo de respuesta y resolución

## ✨ Características Principales
- ✅ Creación y categorización de tickets
- ✅ Sistema de prioridades (Baja, Media, Alta, Crítica)
- ✅ Asignación automática a técnicos disponibles
- ✅ Seguimiento de estado en tiempo real
- ✅ Panel de administración con estadísticas
- ✅ Notificaciones automáticas por email
- ✅ Historial completo de comunicaciones
- ✅ Base de conocimientos integrada
